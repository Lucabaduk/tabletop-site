# Menu photos
All files in assets/menu/*.webp were AI-generated for TableTop (Grok Bot image generation, Oct 2026).
No third-party photos, no hotlinks. Free to use in TableTop and its demo. 400x400 WebP, quality 72.
Path format used by menu items: `assets/menu/<slug>.webp` (slug = lowercase name, non-alphanumerics -> "-").
